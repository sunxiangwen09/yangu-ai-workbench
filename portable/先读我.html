衍谷AI自媒体获客工作台

本机版 0.8 · 2026-11-05

打开工作台

  1. 完整解压文件夹。
  2. Windows 双击 Start-Windows.cmd；Mac 双击 Start-Mac.command。
  3. 保留启动窗口。浏览器自动打开；未打开时访问 本机入口。
  4. 点页面右上角进入“AI 设置”，选择生成方式，应用后检查连接。
  5. 输入行业 → 一键补全客户与服务（可修改）→ 选择干货、观点、故事或记录过程与 1–20 条数量 → 生成并选一题写稿。只填行业直接点生成，也会先补全。IP 建档可跳过。

选择 AI 通道

方式准备当前用途
Codex 本机账号本机安装 Codex，并用自己的 ChatGPT 账号登录。未安装可双击 Install-Codex-Windows.cmd 或 Install-Codex-Mac.command；安装需要网络。业务选题、连续口播、已有原文与评论拆解。不填 API Key，使用 Codex 套餐额度，仍需联网。
DeepSeek API选择 DeepSeek，填写官方平台密钥，应用并检查连接。默认 deepseek-flash，可改为账户支持的模型。同上；由 DeepSeek API 账户付费。此通道暂未接联网检索、视频转写。
OpenAI API填写自己的 OpenAI 密钥及可用模型。文字生成、可选公开网页检索、音视频转写。API 计费与订阅分别核验。

通道必须手动选择；不能从密钥外观识别平台。调用失败不自动重试、不改走其他付费通道。连接检查与真实生成分开验收。

选题卡默认只显示标题、类型与写脚本入口，点击“查看创作思路”看理由、来源、观看动机和拍摄思路。故事或过程脚本需补充真实事件/过程素材，避免编造客户经历。流量机制是待验证的策划判断，不是播放量预测。

视频拆解

粘贴真实逐字稿和评论，或导入 TXT/SRT/VTT/原工作台 JSON 证据包，再点击拆解。只有 OpenAI API 通道接了音视频转写（文件 ≤24 MB）。抖音链接仅尝试公开直接可取得的媒体，不保证成功；平台限制时需自己准备授权素材或原文。未接自动评论采集，不以标题代替原文。

保留的窗口

IP 资料、找选题、写脚本、博主研究、视频制作、审核发布、数据复盘、变现承接、平台模型、流程总览、素材知识、问题清单、历史导出均保留。制作与发布仅保存方案或草稿，不执行剪辑、上传或定时发布；复盘数据手工录入。知识笔记暂不自动注入生成。

资料与密钥

密钥仅保留在启动进程内存，退出后重填。不会写入工程、浏览器存储或压缩包。Codex 登录由官方客户端管理；不复制、不分发登录文件。换电脑需要重新登录 Codex，或重新输入自己的 API Key。

业务资料、历史保存在系统用户目录下的 YanguAI-LocalData，不在程序包里，不自动跨设备同步。导出会包含业务资料，不含密钥。此版没有多客户权限隔离，不用于共享客户账户或敏感资料。

演示前自检

Windows 先双击 Check-Windows.cmd，再启动并真实生成一次。优先 Windows 11 x64；Mac 需 macOS 13.5 以上。未在 Windows 实机运行过，不能用 Mac 测试替代 Windows 验收。网络、账号权限和额度均可能影响生成。不要关闭系统安全保护。

不要同时运行新旧两份工作台。升级前保存输入并关闭旧启动窗口；密钥需重新填写。不同端口同时读写同一份本机资料可能冲突。

工程与开发

app/ 是便携工作台源码，source/web-v1/ 是完整业务工程快照；正式迭代以主项目 web-v1 为准。runtime/ 内含 Node v24.22.2、npm 及许可证，不必系统预装 Node。Codex 运行文件不包含在初始包内，官方安装入口固定版本 0.166.0。使用 DeepSeek 不需安装 Codex。

Windows 开发用 Dev-Windows.cmd；测试：node --test test/*.test.mjs。这里是本机版，不会改变线上旧站。
